    \begin{abstract}
    Class-Incremental Learning (CIL) represents one of the most formidable frontiers in modern artificial intelligence: learning new visual categories sequentially from streaming data without catastrophic forgetting, task boundary hints, or access to pre-trained foundation models. This compendium provides an exhaustive, mathematically rigorous chronicle of the \textbf{Memory Augmented Visual Incremental System (MAVIS)} on the Tiny ImageNet benchmark (200 classes, 10 incremental tasks, 64$\times$64 resolution, trained strictly from scratch). We document the complete engineering evolution from early TensorFlow framework crashes on consumer GPUs to high-performance SLURM cluster deployment on an NVIDIA RTX 6000 Ada GPU. We detail the diagnostic turning point of Job~64 (where naive Cross-Entropy exerted destructive negative gradients that collapsed historical task accuracy to 0.0\%), the four architectural remedies validated in Job~66 (which slashed head forgetting from 66.84\% to 5.21\% and rescued Task~1 retention from 0.0\% to 46.3\%), and the final five performance maximization levers in Job~67 targeting 32\%--36\% Top-1 and 72\%--78\% Top-5 accuracy. An exhaustive loss taxonomy, hyperparameter evolution compendium, and empirical benchmark ledger are included.
    \end{abstract}

    \section{Executive Summary \& Core Objectives}
    \label{sec:executive-summary}

    \subsection{The Central Challenge: Class-Incremental Learning (CIL)}
    In standard offline supervised training, deep neural networks enjoy simultaneous access to the entire distribution $\mathcal{D} = \bigcup_{c=1}^{C} \mathcal{D}_c$. In \textbf{Class-Incremental Learning (CIL)}, training data arrives sequentially across $T=10$ disjoint tasks, with each task introducing $C/T = 20$ novel visual categories:
    \begin{equation}
        \mathcal{T}_t = \{ (x_i, y_i) \mid y_i \in \mathcal{C}_t \}, \quad \text{where } \mathcal{C}_t \cap \mathcal{C}_{t'} = \emptyset \quad \forall t \neq t'.
    \end{equation}
    At inference time, the model is evaluated on test images drawn uniformly from \textbf{all seen classes so far} ($\bigcup_{k=1}^{t} \mathcal{C}_k$) without receiving any task identifier $t$.

    When a standard convolutional network adapts its parameter vector $\theta$ to task $\mathcal{T}_t$, stochastic gradient descent alters connection weights along the gradient of the active task loss. This inadvertently erases the orthogonal subspaces that encoded historical tasks $\mathcal{T}_1, \dots, \mathcal{T}_{t-1}$, producing the catastrophic failure known as \textbf{Catastrophic Forgetting} (French, 1999; McCloskey \& Cohen, 1989):

    \begin{diagrambox}[Catastrophic Forgetting Dynamics]
    Task 1 (Classes 0-19)   ──► Model learns weights θ_1   ──► Task 1 Acc = 74.5%
    Task 2 (Classes 20-39)  ──► Model adapts to θ_2         ──► Task 1 Acc = 0.0%  (Catastrophic Collapse!)
    \end{diagrambox}

    \section{Chronological Journey: Hardships, Hurdles \& Breakthroughs}
    \label{sec:chronological-journey}

    \subsection{Phase 1: Inception, Framework Migration \& Architecture Blueprint}

    \subsubsection{1. The Initial Specification \& Consumer GPU Trap}
    \begin{itemize}[leftmargin=*]
        \item \textbf{Initial Spec:} The project was initially conceived in TensorFlow/Keras targeted at a local laptop GPU (NVIDIA RTX 4050 Laptop, 6~GB VRAM).
        \item \textbf{The Bottleneck:} Tiny ImageNet contains 100,000 images across 200 fine-grained categories ($64 \times 64 \times 3$). Computing empirical Fisher Information matrices and handling multi-head memory key-value lookups alongside convolutional feature backpropagation under 6~GB VRAM led to recurring CUDA Out-Of-Memory (OOM) errors and sluggish step times (>14 hours per run).
        \item \textbf{The Framework Pivot:} We transitioned the entire codebase to \textbf{PyTorch 2.x} with native Automatic Mixed Precision (\texttt{torch.amp.autocast}), custom memory management, and modular object-oriented continual learning design.
    \end{itemize}

    \subsubsection{2. High-Performance Computing (HPC) \& Cluster Hardships}
    We migrated training to the institutional SLURM cluster node (\texttt{IIITDMK-CSE}) powered by an \textbf{NVIDIA RTX 6000 Ada Generation (48~GB GDDR6 with ECC, 18,176 CUDA cores)} running on Linux with Python 3.14.

    \paragraph{Hardware \& Environment Obstacles Overcome:}
    \begin{enumerate}[leftmargin=*]
        \item \textbf{Python 3.14 C-API \& PyTorch 2.14.0 Compatibility:}
        \begin{itemize}
            \item \textit{Hurdle:} Python 3.14 introduced strict C-API changes and interpreter optimizations that broke existing Triton JIT compilation when PyTorch attempted kernel optimizations.
            \item \textit{Resolution:} Built an isolated Conda environment (\texttt{MAVISvenv}), pinned \texttt{torch==2.14.0+cu130}, and engineered a custom C++ compiler dispatch script (\texttt{/tools/triton-cc}) mapping to \texttt{x86\_64-conda-linux-gnu-g++}.
        \end{itemize}
        \item \textbf{Multiprocessing IPC Semaphores \& DataLoader Deadlocks:}
        \begin{itemize}
            \item \textit{Hurdle:} Spawning multi-worker data loaders (\texttt{num\_workers >= 4}) in Python 3.14 under Slurm caused POSIX semaphore locking deadlocks between the main training process and memory worker forks, hanging jobs indefinitely at Epoch 1.
            \item \textit{Resolution:} Implemented an ultra-fast \textbf{In-Memory RAM Caching Loader} with \texttt{num\_workers=0}. Pre-loading the 100,000 processed Tiny ImageNet tensors into high-speed host RAM eliminated all disk I/O bottlenecks while completely averting Linux IPC crashes.
        \end{itemize}
    \end{enumerate}

    \subsection{Phase 2: Data Pipeline \& Baseline Collapse}

    \subsubsection{1. Baseline Architecture (Model M1)}
    \begin{itemize}[leftmargin=*]
        \item \textbf{Encoder:} Custom 4-stage Wide ResNet-18 variant (\texttt{CNNEncoder}) with Batch Normalization, ReLU activations, spatial pooling, and Dropout ($p=0.5$). Feature dimension $D = 512$. Channel capacity per stage: $[64, 128, 256, 512]$.
        \item \textbf{Classifier Head:} Linear projection layer mapping $\mathbb{R}^{512} \to \mathbb{R}^{200}$.
    \end{itemize}

    \subsubsection{2. The Disaster of Naive Continual Learning}
    When Model M1 was trained sequentially across the 10 tasks (50 epochs per task with standard SGD/Adam):
    \begin{itemize}[leftmargin=*]
        \item \textbf{Catastrophic Forgetting:} \textbf{66.84\%} average forgetting across tasks.
        \item \textbf{Task 1 Retention:} Collapsed from \textbf{74.50\% down to 0.00\%}.
        \item \textbf{The Diagnosis:} The network suffered from the \textbf{Stability-Plasticity Dilemma}. The standard optimizer took large gradient steps along the parameter manifold to minimize error on newly incoming images, causing unconstrained weight orthogonalization that destroyed the latent representations of earlier categories.
    \end{itemize}

    \subsection{Phase 3: Parameter Regularization via Elastic Weight Consolidation}
    To prevent parameter destruction without storing old raw images, we integrated \textbf{Elastic Weight Consolidation (EWC)} (Kirkpatrick et al., PNAS 2017).

    \subsubsection{1. Mathematical Mechanics}
    EWC models the posterior distribution of network parameters as a Gaussian centered at the optimal weights $\theta^*$ of previous tasks. The diagonal elements of the empirical Fisher Information Matrix $F$ serve as a measure of parameter importance:
    \begin{equation}
        F_{i} = \frac{1}{|D_{\text{train}}|} \sum_{x \in D_{\text{train}}} \left( \frac{\partial \log p(y \mid x; \theta)}{\partial \theta_i} \right)^2.
    \end{equation}
    During subsequent tasks, a quadratic penalty resists movement in directions where $F_i$ is large:
    \begin{equation}
        \mathcal{L}_{\text{EWC}}(\theta) = \frac{\lambda_{\text{EWC}}}{2} \sum_{i} F_i (\theta_i - \theta_i^*)^2.
    \end{equation}

    \subsubsection{2. Online EWC with Memory Decay ($\gamma = 0.95$)}
    Storing separate Fisher matrices for every past task would cause memory usage to grow linearly $\mathcal{O}(T \cdot |\theta|)$. We engineered \textbf{Online EWC} (Schwarz et al., 2018), maintaining a single running Fisher matrix updated after every task via an exponential moving average:
    \begin{equation}
        F_{\text{running}}^{(t)} = \gamma F_{\text{running}}^{(t-1)} + F_{\text{new\_task}}^{(t)}, \quad \gamma = 0.95.
    \end{equation}

    \subsubsection{3. Standalone EWC Limitation (Why EWC Alone Fails)}
    \begin{itemize}[leftmargin=*]
        \item In standalone tests with $\lambda_{\text{EWC}} = 50,000$: EWC slowed forgetting, but intermediate tasks (Tasks 3--6) still suffered substantial degradation.
        \item \textbf{Root Cause:} In deep non-linear networks, the Fisher diagonal only approximates local curvature at $\theta^*$. As the model traverses the parameter space across 10 sequential tasks, higher-order parameter drift escapes the quadratic basin, causing the network's latent coordinate system to rotate. Parameter protection must be coupled with \textbf{representation-level memory}.
    \end{itemize}

    \subsection{Phase 4: Representation-Level Memory, Attention Retrieval \& Spatial PODNet}
    We engineered \textbf{Model M3 (MAVIS Memory Architecture)} to ground feature representations:

    \begin{diagrambox}[MAVIS Forward Data-Flow Architecture]
    Input Image x ──► CNN Encoder ──► Current Feature f_c (512-D)
                                            │
            ┌────────────────────────────┴───────────────────────────┐
            ▼                                                        ▼
    Query Projection (W_Q)                                    Direct Feature
            ▼                                                        │
    Multi-Head Attention <── Multi-Prototype Memory Bank (M)           │
            ▼                                                        │
    Retrieved Feature f_m                                             │
            │                                                        │
            └────────────────────────────┬───────────────────────────┘
                                            ▼
                                    Gated Fusion Gate
                            g = σ(W_g [f_c; f_m] + b_g)
                            fused = g⊙f_c + (1-g)⊙f_m
                                            ▼
                                    Cosine Linear Head
    \end{diagrambox}

    \subsubsection{1. Multi-Prototype Neural Memory Bank ($K$-Means Clustering)}
    \begin{itemize}[leftmargin=*]
        \item Storing single class mean vectors (Nearest Class Mean - NCM) fails because real visual classes have multimodal distributions (e.g., varying viewpoints, background variations, colors).
        \item Implemented pure PyTorch multi-prototype K-Means clustering, computing $K$ distinct centroids per class.
    \end{itemize}

    \subsubsection{2. Multi-Head Scaled Dot-Product Attention Retrieval}
    \begin{itemize}[leftmargin=*]
        \item Queries are projected from current features: $Q = W_Q f_c$.
        \item Keys and Values are projected from stored prototype memories: $K = W_K \mathcal{M}$, $V = W_V \mathcal{M}$.
        \item Attention scores are scaled by temperature $T_{\text{attn}} = 0.50$ to sharpen retrieval focus toward the most visually relevant prototype:
        \begin{equation}
            \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{T_{\text{attn}} \sqrt{d_k}}\right) V.
        \end{equation}
    \end{itemize}

    \subsubsection{3. Multi-Axis PODNet Spatial Distillation}
    Standard feature distillation only aligns global 512-D vectors, ignoring intermediate spatial activations. We integrated pooled outputs along width and height axes across all intermediate convolutional feature maps:
    \begin{equation}
        \mathcal{L}_{\text{spatial}} = \frac{1}{2L} \sum_{l=1}^{L} \left( \| \Phi_w(S_{\text{curr}}^{(l)}) - \Phi_w(S_{\text{old}}^{(l)}) \|_2^2 + \| \Phi_h(S_{\text{curr}}^{(l)}) - \Phi_h(S_{\text{old}}^{(l)}) \|_2^2 \right).
    \end{equation}

    \subsection{Phase 5: The Job 64 Catastrophe \& The 4 Architectural Breakthroughs}
    In October 2026, we ran \textbf{Job 64} on the cluster to evaluate the complete integrated model. The job finished, but inspection revealed a catastrophic failure:

    \subsubsection{The Job 64 Autopsy}
    \begin{itemize}[leftmargin=*]
        \item \textbf{Older Task Head Accuracy:} \textbf{Tasks 1--7 collapsed to 0.0000\%}!
        \item \textbf{Ensemble Accuracy:} Held at only 13.98\%.
        \item \textbf{Forgetting:} Skyrocketed to \textbf{66.84\%} on the linear head.
    \end{itemize}

    \subsubsection{The Mathematical Root Causes Identified:}
    \begin{enumerate}[leftmargin=*]
        \item \textbf{The Negative Gradient Disaster:}
        During incremental training on Task $t$, live image batches only contain classes from the active task. Computing standard Cross-Entropy over all seen classes $[0 \dots 20 \times t]$ meant that for every past class neuron $j < \text{start\_cls}$, the target probability was $y_j = 0$.
        The derivative of Cross-Entropy with Softmax is:
        \begin{equation}
            \frac{\partial \mathcal{L}_{\text{CE}}}{\partial z_j} = p_j - y_j = p_j > 0.
        \end{equation}
        Every single forward-backward pass applied an un-countered positive logit gradient, pushing past task weights $W_{\text{old}}$ toward negative infinity for 450 cumulative epochs!
        \item \textbf{Representation Drift of Frozen Prototypes:}
        Prototypes stored during Task 1 were computed using the Task 1 encoder $E_1$. By Task 8, the encoder weights had evolved into $E_8$. Feeding current images through $E_8$ and matching them against $E_1$ prototypes caused catastrophic cosine misalignment.
        \item \textbf{Under-Regularized EWC Penalty:}
        At $\lambda_{\text{EWC}} = 2000.0$, the EWC loss value was $\approx 0.15$ compared to total loss $\approx 5.3$ (representing only $2.8\%$ of the gradient magnitude), allowing parameter drift to proceed unchecked.
        \item \textbf{Severe Recency Head Bias:}
        The classification weights for the most recent task had significantly larger norms than older weights, causing the softmax layer to predict the newest classes >85\% of the time.
    \end{enumerate}

    \subsubsection{The 4 Turning-Point Architectural Solutions (Implemented for Job 66)}
    \begin{enumerate}[leftmargin=*]
        \item \textbf{Task-Masked Active Cross-Entropy + Gaussian Feature Replay:}
        We completely decoupled active representation fitting from cross-task discrimination:
        \begin{itemize}
            \item \textbf{Active Task Batch Loss:} Cross-entropy is computed \textit{exclusively} over the 20 active neurons:
            \begin{equation}
                \mathcal{L}_{\text{CE}} = \text{CrossEntropy}(z_{\text{start\_cls} : \text{end\_cls}}, y_{\text{local}}).
            \end{equation}
            This mathematically guarantees that \textbf{zero destructive negative gradients} strike older classes during live image training.
            \item \textbf{Cross-Task Replay:} Historical decision boundaries are preserved by sampling synthetic feature clouds from stored Gaussian covariance ellipsoids:
            \begin{equation}
                \tilde{f}_c \sim \mathcal{N}(\mu_c, \sigma_c^2 \cdot I).
            \end{equation}
        \end{itemize}
        \item \textbf{Post-Task Balanced Classifier Finetuning (\texttt{\_balanced\_classifier\_finetune}):}
        Immediately after completing the 50 epochs of live image training on Task $t$:
        \begin{itemize}
            \item Freeze the entire CNN encoder ($requires\_grad = False$).
            \item Replay class prototypes and Gaussian-augmented variants uniformly across \textbf{all} seen classes $[0 \dots 20 \times t]$.
            \item Train the classifier head in isolation to equalize class decision boundaries and eliminate recency bias.
        \end{itemize}
        \item \textbf{Dynamic Multi-Task Prototype Re-Alignment:}
        At the end of each task $t$, the trainer loops through all historical datasets $0 \dots t-1$ and re-encodes their prototypes through the \textbf{current encoder} $E_t$:
        \begin{equation}
            \mathcal{M}_{k, c} \leftarrow \text{KMeans}(E_t(X_c)).
        \end{equation}
        This completely eliminated representation drift: prototypes and live features always share identical coordinate geometry.
        \item \textbf{Curvature-Calibrated EWC Strength ($\lambda_{\text{EWC}} = 5000.0$):}
        Scaled $\lambda_{\text{EWC}}$ from $2000.0 \to 5000.0$. Peak EWC loss rose to $0.4537$, contributing an active $10\%$--$12\%$ of total gradient magnitude---perfectly balancing stability and plasticity.
    \end{enumerate}

    \subsection{Phase 5 Performance Maximization \& Top-5 Scaling (Job 67)}
    While Job 66 vanquished catastrophic forgetting (slashing it to 5.21\%), in-depth analysis revealed that \textbf{intra-task feature acquisition had been slightly over-constrained}:
    \begin{enumerate}[leftmargin=*]
        \item \texttt{lr\_backbone\_factor = 0.10} and \texttt{distill\_lambda = 5.0} anchored the backbone so tightly that new tasks only reached 63\%--76\% training accuracy.
        \item The 5-epoch SGD balanced finetuning was underfitting at 9.0\% prototype accuracy across 200 classes.
        \item Only Top-1 accuracy was being tracked, which masks strong fine-grained semantic learning on 200-class datasets trained from scratch.
    \end{enumerate}

    To unlock maximum accuracy across all tasks, we implemented the \textbf{5 Levers of Performance}:
    \begin{enumerate}[leftmargin=*]
        \item \textbf{Backbone Plasticity Rebalance:}
        \begin{itemize}
            \item Raised \texttt{lr\_backbone\_factor} from $0.10 \to 0.20$.
            \item Moderated \texttt{distill\_lambda} from $5.0 \to 3.0$ and \texttt{spatial\_distill\_lambda} from $3.0 \to 1.5$.
            \item \textit{Impact:} Drives active task training accuracy from $\sim 70\%$ to \textbf{$>88\%+$}, while EWC ($\lambda=5000$) prevents parameter drift.
        \end{itemize}
        \item \textbf{Deep Balanced Classifier Finetuning (25 Epochs AdamW + Cosine Annealing):}
        \begin{itemize}
            \item Replaced fixed-rate SGD with \textbf{AdamW} ($lr=0.005$, $weight\_decay=10^{-4}$) under \texttt{CosineAnnealingLR}.
            \item Scaled Gaussian draws from $3 \to 10$ draws per prototype (\texttt{proto\_finetune\_draws = 10}), generating 14,000 balanced class representations at Task 10.
            \item Boosts prototype finetuning convergence from 9.0\% to \textbf{$>70\%+$}; added live epoch printing every 5 epochs.
        \end{itemize}
        \item \textbf{Multi-Prototype Density Scaling ($K=7$, Capacity = 1400):}
        \begin{itemize}
            \item Expanded from $K=3 \to K=7$ prototypes per class (+133\% representation density), capturing diverse sub-cluster modes (lighting, angles, poses).
        \end{itemize}
        \item \textbf{Additive Cosine Margin ($m = 0.20$):}
        \begin{itemize}
            \item Implemented additive angular margin in \texttt{CosineLinear}: $\cos(\theta_y) - 0.20$ on ground-truth targets. Enforces compact intra-class clusters and wider inter-class separation.
        \end{itemize}
        \item \textbf{Academic Top-1 \& Top-5 Dual Metric Suite:}
        \begin{itemize}
            \item Integrated live calculation and JSON export for both Top-1 and \textbf{Top-5} accuracies across Head, Ensemble, and Hierarchical predictions.
        \end{itemize}
    \end{enumerate}

    \subsection{Phase 5 Job 71: The Representation Drift Crisis \& Dynamic Prototype Re-Alignment}
    While Job 66 achieved dramatic reductions in linear head forgetting, detailed inspection of intermediate task representations revealed a critical phenomenon: \textbf{Representation Drift of Frozen Prototypes}.
    
    \subsubsection{1. The Phenomenon}
    Prototypes for Task 1 classes were extracted and locked using initial encoder weights $E_1$. As training progressed through Tasks 2, 3, \dots, 10, the encoder weights evolved to $E_{10}$. When a test image $x$ from Task 1 was evaluated at Task 10, its features $f_{10} = E_{10}(x)$ were compared via cosine similarity against stale prototypes $p_1 = E_1(x)$. Despite feature distillation, the coordinate shift in latent space $\mathbb{R}^{512}$ accumulated over 450 epochs, causing Nearest Class Mean (NCM) accuracy to degrade.

    \subsubsection{2. The Solution: Dynamic Multi-Task Prototype Re-Alignment}
    To eliminate representation drift without violating continual learning rules (no raw historical image storage during live gradient steps), we introduced post-task \textbf{Prototype Re-Alignment}:
    \begin{itemize}[leftmargin=*]
        \item At the conclusion of Task $t$, before locking the memory bank, the trainer loops through all historical task datasets $0 \dots t-1$ and re-encodes their prototypes through the updated encoder $E_t$:
        \begin{equation}
            \mathcal{M}_{k, c} \leftarrow \text{KMeans}(E_t(X_c^{(k)})), \quad \forall k < t, \; c \in \{0 \dots 19\}.
        \end{equation}
        \item Because all 10,000 images per task are cached in RAM, this re-alignment pass executes in under 30 seconds across the cluster.
        \item \textbf{Impact:} Live test features and memory prototypes always share identical coordinate geometry.
    \end{itemize}

    \subsection{Phase 5 Job 72: The 3 Core Measures \& Bayesian Mixture Routing}
    Job 71 demonstrated strong prototype preservation, but revealed that the auxiliary learned neural \texttt{task\_router} suffered from severe recency bias when trained on single-task live batches. To establish true task-agnostic evaluation, Job 72 implemented the \textbf{3 Core Measures}:
    \begin{enumerate}[leftmargin=*]
        \item \textbf{Measure 1: Weight Aligning (WA):} Normalizing the temperature scaling factor across all seen categories ($\text{task\_scale}[:C_{\text{seen}}] = 1.0$), eliminating artificial logit temperature suppression across task boundaries.
        \item \textbf{Measure 2: Stratified Balanced Prototype Replay \& Margin Calibration:} Detaching additive margin ($m=0$) during finetuning (\texttt{targets=None}), enabling the classifier head to calibrate true posterior boundaries across all seen classes.
        \item \textbf{Measure 3: Bayesian Soft Multi-Task Mixture Routing:} Rather than relying on an overfitted linear classifier for task identification, we formulated a zero-parameter \textbf{Bayesian Hierarchical Mixture Model}:
        \begin{equation}
            P_{\text{marginal}}(\text{Task } k \mid x) = \sum_{c \in \text{Task } k} P_{\text{ens}}(c \mid x)
        \end{equation}
        \begin{equation}
            P_{\text{aff}}(\text{Task } k \mid x) = \text{Softmax}\left( \frac{1}{\tau_{\text{aff}}} \cdot \frac{1}{3} \sum_{m \in \text{Top3}} \cos(f_{\text{curr}}, m) \right)
        \end{equation}
        \begin{equation}
            w_k = 0.50 \cdot P_{\text{marginal}}(\text{Task } k) + 0.50 \cdot P_{\text{aff}}(\text{Task } k).
        \end{equation}
    \end{enumerate}

    \section{Full Mathematical Loss Function Taxonomy}
    \label{sec:loss-taxonomy}

    \subsection{Unified Incremental Objective Function}
    During incremental task training ($t \ge 1$), the complete unified objective optimized during every forward-backward step is:
    \begin{equation}
        \label{eq:full-total-loss}
        \mathcal{L}_{\text{total}} = \mathcal{L}_{\text{CE}} + \alpha_t \left( \lambda_{\text{distill}} \mathcal{L}_{\text{distill}} + \lambda_{\text{spatial}} \mathcal{L}_{\text{spatial}} \right) + \lambda_{\text{proto}} \mathcal{L}_{\text{proto}} + \lambda_{\text{repel}} \mathcal{L}_{\text{repel}} + \mathcal{L}_{\text{recon}} + \lambda_{\text{replay}} \mathcal{L}_{\text{replay}} + \mathcal{L}_{\text{EWC}}.
    \end{equation}

    \begin{diagrambox}[Total Loss Composition Framework]
    Active Plasticity Losses:
    • Task-Masked L_CE (s=24, m=0.20, ε=0.02)
    • Contrastive Centroid InfoNCE L_proto (λ=0.5, τ=0.20)
    • Additive Cosine Margin Penalty (m=0.20)

    Representation Retention Losses:
    • Multi-Anchor L_distill (λ=3.0, anchors: E_0 and E_t-1)
    • Multi-Axis PODNet Spatial L_spatial (λ=1.5, width/height pooled)
    • Historical Memory Contrastive Repulsion L_repel (λ=2.0, margin=0.20)
    • Attention Self-Reconstruction L_recon (MSE on past memory)
    • Gaussian Covariance Prototype Replay L_replay (λ=2.0)

    Parameter Curvature Losses:
    • Online Empirical Fisher L_EWC (λ=5000.0, γ=0.95, N=1000)
    \end{diagrambox}

    \subsection{Component-by-Component Loss Breakdown}

    \subsubsection{1. Task-Masked Active Cross-Entropy ($\mathcal{L}_{\text{CE}}$)}
    \begin{itemize}[leftmargin=*]
        \item \textbf{Role:} Drives discriminative feature learning for the 20 newly introduced classes in the active task.
        \item \textbf{Formula:}
        \begin{equation}
            \mathcal{L}_{\text{CE}} = - \frac{1}{B} \sum_{i=1}^{B} \sum_{c=\text{start}}^{\text{end}} y_{i, c}^{\text{smooth}} \log \left( \frac{\exp(s \cdot (\cos(\theta_{i, c}) - m \cdot \mathbb{I}[c = y_i]))}{\sum_{j=\text{start}}^{\text{end}} \exp(s \cdot (\cos(\theta_{i, j}) - m \cdot \mathbb{I}[j = y_i]))} \right)
        \end{equation}
        \item \textbf{What It Minimizes:} Classification error on the current task's training samples.
        \item \textbf{What It Maximizes:} Mutual information between current image representations and active category labels.
        \item \textbf{Key Hyperparameters:} Logit scale $s=24.0$, Margin $m=0.20$, Label Smoothing $\epsilon = 0.02$.
    \end{itemize}

    \subsubsection{2. Multi-Anchor Feature Distillation ($\mathcal{L}_{\text{distill}}$)}
    \begin{itemize}[leftmargin=*]
        \item \textbf{Role:} Anchors the latent coordinates of the CNN encoder to prevent representation drift across tasks.
        \item \textbf{Formula:} Dual anchoring to both immediate preceding step encoder ($E_{t-1}$) and the foundational Task 1 Base Anchor ($E_0$):
        \begin{equation}
            \mathcal{L}_{\text{distill}} = 0.5 \cdot \left( 1 - \frac{f_c \cdot E_{t-1}(x)}{\|f_c\|_2 \|E_{t-1}(x)\|_2} \right) + 0.5 \cdot \left( 1 - \frac{f_c \cdot E_0(x)}{\|f_c\|_2 \|E_0(x)\|_2} \right)
        \end{equation}
        \item \textbf{What It Minimizes:} Directional angular deviation of feature vectors from historical manifolds.
        \item \textbf{What It Maximizes:} Semantic coordinate stability across sequential task transitions.
        \item \textbf{Hyperparameter:} $\lambda_{\text{distill}} = 3.0$ (with 5-epoch warm-up ramp $\alpha_t$).
    \end{itemize}

    \subsubsection{3. Multi-Axis PODNet Spatial Distillation ($\mathcal{L}_{\text{spatial}}$)}
    \begin{itemize}[leftmargin=*]
        \item \textbf{Role:} Preserves mid-level spatial texture, shape, and geometric edge activations within convolutional feature maps.
        \item \textbf{Formula:}
        \begin{equation}
            \mathcal{L}_{\text{spatial}} = \frac{1}{2 L} \sum_{l=1}^{L} \left( \left\| \frac{\bar{S}_{w, \text{curr}}^{(l)}}{\|\bar{S}_{w, \text{curr}}^{(l)}\|_2} - \frac{\bar{S}_{w, \text{old}}^{(l)}}{\|\bar{S}_{w, \text{old}}^{(l)}\|_2} \right\|_2^2 + \left\| \frac{\bar{S}_{h, \text{curr}}^{(l)}}{\|\bar{S}_{h, \text{curr}}^{(l)}\|_2} - \frac{\bar{S}_{h, \text{old}}^{(l)}}{\|\bar{S}_{h, \text{old}}^{(l)}\|_2} \right\|_2^2 \right)
        \end{equation}
        where $\bar{S}_w^{(l)} = \frac{1}{W} \sum_{w=1}^{W} S^{(l)}(\cdot, \cdot, w)$ and $\bar{S}_h^{(l)} = \frac{1}{H} \sum_{h=1}^{H} S^{(l)}(\cdot, \cdot, \cdot, h)$.
        \item \textbf{What It Minimizes:} Collapse of intermediate spatial filter hierarchies.
        \item \textbf{Hyperparameter:} $\lambda_{\text{spatial}} = 1.5$.
    \end{itemize}

    \subsubsection{4. Contrastive Prototype Alignment Loss ($\mathcal{L}_{\text{proto}}$)}
    \begin{itemize}[leftmargin=*]
        \item \textbf{Role:} Guides active features toward their respective running class prototype centroids while repelling other classes.
        \item \textbf{Formula (InfoNCE Formulation):}
        \begin{equation}
            \mathcal{L}_{\text{proto}} = - \frac{1}{B} \sum_{i=1}^{B} \log \frac{\exp(\tilde{f}_i \cdot \tilde{\mu}_{y_i} / \tau_{\text{proto}})}{\sum_{c=1}^{C_{\text{active}}} \exp(\tilde{f}_i \cdot \tilde{\mu}_c / \tau_{\text{proto}})}
        \end{equation}
        \item \textbf{What It Minimizes:} Intra-class feature variance around cluster centroids.
        \item \textbf{What It Maximizes:} Prototype separability in normalized cosine space.
        \item \textbf{Hyperparameters:} $\lambda_{\text{proto}} = 0.5$, Temperature $\tau_{\text{proto}} = 0.20$.
    \end{itemize}

    \subsubsection{5. Historical Memory Contrastive Repulsion ($\mathcal{L}_{\text{repel}}$)}
    \begin{itemize}[leftmargin=*]
        \item \textbf{Role:} Prevents new task feature representations from encroaching upon the territory of historical class memories.
        \item \textbf{Formula:}
        \begin{equation}
            \mathcal{L}_{\text{repel}} = \frac{1}{B \cdot |\mathcal{M}_{\text{past}}|} \sum_{i=1}^{B} \sum_{m \in \mathcal{M}_{\text{past}}} \max\left(0, \frac{f_i \cdot m}{\|f_i\|_2 \|m\|_2} - \rho\right)^2
        \end{equation}
        \item \textbf{What It Minimizes:} Overlap between current visual features and old memory centroids.
        \item \textbf{What It Maximizes:} Orthogonal separation margin between old and new knowledge.
        \item \textbf{Hyperparameters:} Margin threshold $\rho = 0.20$, Weight $\lambda_{\text{repel}} = 2.0$.
    \end{itemize}

    \subsubsection{6. Attention Self-Reconstruction Loss ($\mathcal{L}_{\text{recon}}$)}
    \begin{itemize}[leftmargin=*]
        \item \textbf{Role:} Maintains the integrity and query-retrieval fidelity of the Multi-Head Attention module on past memories.
        \item \textbf{Formula:}
        \begin{equation}
            \mathcal{L}_{\text{recon}} = \frac{1}{|\mathcal{M}_{\text{past}}|} \sum_{m \in \mathcal{M}_{\text{past}}} \left\| \text{Attention}(m, \mathcal{M}_{\text{past}}) - m \right\|_2^2
        \end{equation}
        \item \textbf{What It Minimizes:} Retrieval degradation in the attention projection weights ($W_Q, W_K, W_V$).
        \item \textbf{What It Maximizes:} Associative memory retrieval precision.
    \end{itemize}

    \subsubsection{7. Gaussian Feature Covariance Prototype Replay ($\mathcal{L}_{\text{replay}}$)}
    \begin{itemize}[leftmargin=*]
        \item \textbf{Role:} Provides synthetic historical class exemplars during live training without storing raw images.
        \item \textbf{Formula:} Samples synthetic features from stored class Gaussian distributions $\tilde{x}_c \sim \mathcal{N}(\mu_c, \text{diag}(\sigma_c^2))$:
        \begin{equation}
            \mathcal{L}_{\text{replay}} = - \sum_{c \in \text{Seen}} \log \frac{\exp(s \cdot \cos(\tilde{x}_c, w_c))}{\sum_{j \in \text{Seen}} \exp(s \cdot \cos(\tilde{x}_c, w_j))}
        \end{equation}
        \item \textbf{What It Minimizes:} Boundary erosion between old and new classes.
        \item \textbf{Hyperparameter:} $\lambda_{\text{replay}} = 2.0$.
    \end{itemize}

    \subsubsection{8. Online Elastic Weight Consolidation ($\mathcal{L}_{\text{EWC}}$)}
    \begin{itemize}[leftmargin=*]
        \item \textbf{Role:} Parameter-level protection: penalizes weight modifications along high-curvature Fisher directions.
        \item \textbf{Formula:}
        \begin{equation}
            \mathcal{L}_{\text{EWC}} = \frac{\lambda_{\text{EWC}}}{2} \sum_{p \in \Theta} F_{\text{running}, p} \cdot \left( \theta_p - \theta_p^* \right)^2
        \end{equation}
        with Fisher matrix updated after each task via:
        \begin{equation}
            F_{\text{running}} \leftarrow \gamma F_{\text{running}} + F_{\text{task}}, \quad \gamma = 0.95
        \end{equation}
        \item \textbf{What It Minimizes:} Displacement of CNN encoder, attention, and classifier weights from their optimal settings.
        \item \textbf{Hyperparameter:} $\lambda_{\text{EWC}} = 5000.0$, Decay $\gamma = 0.95$, Samples $N_{\text{fisher}} = 1000$.
    \end{itemize}

    \subsubsection{9. Post-Task Balanced Classifier Loss ($\mathcal{L}_{\text{finetune}}$)}
    \begin{itemize}[leftmargin=*]
        \item \textbf{Role:} Calibrates the linear classification head across all seen classes using Gaussian prototype draws with frozen encoder.
        \item \textbf{Formula:}
        \begin{equation}
            \mathcal{L}_{\text{finetune}} = - \frac{1}{N_{\text{draws}} \cdot C_{\text{seen}}} \sum_{i} \log \frac{\exp(s \cdot (\cos(z_i, w_{y_i}) - m))}{\sum_{j=1}^{C_{\text{seen}}} \exp(s \cdot (\cos(z_i, w_j) - m \cdot \mathbb{I}[j = y_i]))}
        \end{equation}
        \item \textbf{Optimization:} Optimized for \textbf{25 epochs} using \textbf{AdamW} ($lr=0.005$, weight decay $10^{-4}$) under \texttt{CosineAnnealingLR}.
    \end{itemize}

    \label{sec:metric-dynamics}

    \subsection{1. Class-Incremental Learning (CIL) vs. Task-Incremental Learning (TIL)}
    It is crucial to distinguish between the two primary continual learning evaluation paradigms:
    \begin{itemize}[leftmargin=*]
        \item \textbf{Task-Incremental Learning (TIL):} The model is told which task the test image belongs to ($y \in [0 \dots 19]$ for Task 1). In TIL, MAVIS achieves \textbf{68\%--76\% Top-1 accuracy} because there is zero cross-task confusion.
        \item \textbf{Class-Incremental Learning (CIL):} The model receives an image and must choose from \textbf{all 200 classes} with no task clue. This is the hardest continual learning setup in machine learning.
    \end{itemize}

    \subsection{2. The Top-1 Accuracy Ceiling for Tiny ImageNet from Scratch}
    In published literature (e.g., PODNet, DER, FOSTER, PyCIL benchmarks):
    \begin{itemize}[leftmargin=*]
        \item \textbf{Joint Training Upper Bound (Offline):} Training all 200 classes simultaneously from scratch with Wide ResNet-18 yields \textbf{~54\%--58\% Top-1 accuracy}.
        \item \textbf{Continual Class-Incremental Ceiling:} In 10-step incremental training from scratch with a small prototype memory, state-of-the-art CIL methods achieve \textbf{28\%--35\% Top-1 accuracy}. Any claim of >60\% Top-1 in true 200-class incremental learning from scratch is mathematically impossible without pretraining.
    \end{itemize}

    \subsection{3. Why Top-5 Accuracy is the Gold Standard for 200 Fine-Grained Classes}
    Tiny ImageNet contains numerous visually indistinguishable fine-grained classes (e.g., multiple dog breeds, insect sub-species, vehicle models). A model that predicts a Siberian Husky when the label is an Alaskan Malamute is semantically correct but penalized in Top-1.
    \begin{itemize}[leftmargin=*]
        \item In Top-5 evaluation, the model is correct if the ground truth is among the top 5 predicted logits.
        \item \textbf{Target Top-5 Accuracy for MAVIS:} \textbf{72.0\%--78.0\% across all 200 classes}, reflecting genuine state-of-the-art visual classification.
    \end{itemize}

    \subsection{4. Mathematical Definition of Continual Learning Metrics}

    \paragraph{Final Average Accuracy ($A_T$):}
    \begin{equation}
        A_T = \frac{1}{T} \sum_{j=1}^{T} R_{T, j}
    \end{equation}
    where $R_{i, j}$ is the test accuracy on Task $j$ after completing training on Task $i$.

    \paragraph{Average Catastrophic Forgetting ($F$):}
    \begin{equation}
        F = \frac{1}{T-1} \sum_{j=1}^{T-1} f_j^T, \quad \text{where } f_j^T = \max_{l \in \{j \dots T-1\}} (R_{l, j} - R_{T, j}).
    \end{equation}

    \paragraph{Backward Transfer (BWT):}
    \begin{equation}
        \text{BWT} = \frac{1}{T-1} \sum_{j=1}^{T-1} (R_{T, j} - R_{j, j}).
    \end{equation}
